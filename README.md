# Pneumonia_Detect

Capstone Project - Pneumonia Detection using Deep Learning and Streamlit.

## Project Overview
This project predicts whether a chest X-ray image is pneumonia-positive or pneumonia-negative using a trained deep learning model.

## Deployment Files
- app.py
- requirements.txt
- runtime.txt
- final_pneumonia_model.keras

## Deployment Platform
- GitHub
- Streamlit Cloud

## Disclaimer
This application is intended for educational and decision-support purposes only.
It must not be used as a standalone clinical diagnostic tool.
